# B 对象工作区: 生产实现与验证

## 选定基准

用户原话: “B 对象工作区 这一套合适”。
基准文件: `../dir-2.html`。
实际实现位于现有 Next.js/React 组件中,继续使用真实 API、会话、权限与运行内核。

## 对齐结果

| B 的结构 | 生产实现 |
| --- | --- |
| 品牌与搜索顶栏 | 56px,保留 OW 与产品名称,去掉原来的智能体下拉及重复会话名 |
| 左侧对象树 | 264px,智能体下面展示其会话和新建会话入口 |
| 对象标题与工作区 | 智能体名称、状态及“对话 / 配置 / 运行 / 接入” |
| 全局功能 | 全部运行、发现智能体、用量与费用、管理员入口位于树底部,账号菜单置底 |
| 面板样式 | 12px 圆角、6px 间距、既有深灰色板 |
| 对话与工具详情 | 用户和智能体按左侧身份层级排版;工具逐行展开;文件/执行详情按需打开 |
| 输入区 | 独立占据高度,不覆盖消息或问题;移动端检查滚动区底边不超过输入框顶边 |
| 配置页 | 配置、能力、知识、安全与契约、评测、发布与分享;分区切换保留草稿 |
| 保存操作 | 位于面板固定底栏,长表单无需滚到底再保存 |
| 上下文保持 | 切对象时保持当前工作区页签;从配置/运行/接入返回对话时恢复该对象原会话 |

生产数据和能力比原型更多,保留了必须的输入输出契约、真实提问状态、
其他回答输入、版本标识、模型售价、草稿校验、所有者权限和危险操作确认。
只可使用而不可查看配置的智能体不显示配置入口。

## 其他落地内容

- 原有 URL 继续可用;对象运行和接入使用 `?agent=` 明确限定上下文。
- 非法或空对象参数显示错误,不回退到其他智能体或未筛选的全局运行。
- 运行和接入共享对象外壳,凭证绑定与查看哪个智能体的文档仍独立。
- 调用文档保留已发布契约优先规则,不把正在编辑的草稿冒充发布版本。
- 用量与费用归到独立全局区域,保留账户、消耗、流水、套餐和模型价格的不同口径。
- 管理端积分页分概览、账户、对账;提供者与默认模型别名分区。
- 新增 `/admin/runs`、`/admin/audit`、`/admin/market`,复用既有能力并由 requireAdmin 守卫。
- AI 辅助编辑保留真实设计会话,使用同一对象外壳;设计历史放在编辑区控件中。
- 命令面板使用共享导航目录;历史原型保持独立保存。

## 验证记录

- 全量单测: 1,889 通过,36 跳过。跳过项包含需要专用 MySQL/Redis 环境的集成测试。
- 浏览器回归按独立用例计: 19 项通过,2 项 MCP 用例因未放行本机内网而跳过。
  覆盖对象树、深链、会话返回、配置分区草稿、离开提示、非法对象、
  Key 绑定边界、知识编辑/上传、技能文件、移动端抽屉及管理页拒绝普通账号。
- TypeScript 检查通过;IDE build_project 返回成功;本轮修改文件的 Biome 检查通过。
- IDE 批量深度检查返回超时/未完成,不计为完整通过。
- 计费数据库浏览器测试的导航已适配,但因缺少专用测试数据库未执行测试正文。
- 没有触发真实模型运行、充值或修改已有账号角色。
- 新增对象与接入测试使用独立普通测试账号,结束后删除其创建的会话、智能体与 Key。
  账号及审计记录保留,遵循仓库现有注册式测试做法。

首轮有两项测试失败: 知识正文接口尚未返回时的短超时,以及受控 textarea
的包裹 label 文本包含初始值导致精确标签定位失败。前者改为等待正文请求,
后者按浏览器实际可访问名称定位 textbox;修正后通过。

## 无障碍与滚动

沿用现有 Radix 抽屉与 Tabs,页面跳转使用原生链接,不把路由导航伪装成无键盘支持的 tabs。
依据已读取的 modern-web-guidance accessibility:
“Match ARIA implementations to actual behavior”。
移动端保留对象树与执行详情抽屉,并验证关闭操作和页面无横向溢出。
