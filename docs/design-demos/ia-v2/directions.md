# 六个布局候选

共用 spec.md 与 brand-spec.md。同色同内容,比较结构,不比较换皮。

## A 任务分区 / 最佳设计师: Alan Cooper 的目标导向设计视角

借用: 用用户要完成的事情决定全局导航,不暴露后端模块。
主角素材: 一段真实形态的会话、文件与任务运行样例。
骨架: 176px 带标签主导航 + 232px 会话列表 + 对话;执行详情为按需抽屉。
胆量: 删除会话 tabs 和永久右侧栏,把主操作缩到当前任务附近。
form: 从“做事、创建、排错、接 API、看消耗”五种任务生成五个入口。
完整版候选。可发现性最强,迁移成本较低。

## B 对象工作区 / 现实参照: JetBrains New UI

来源: product-facts.md 与 refs/jetbrains.png,已查看官方截图。
借用: 左侧对象浏览、主编辑区、按上下文显示操作,没有第二套全局跳转树。
主角素材: 当前智能体及其会话、配置、运行和接入关系。
骨架: 264px 智能体对象树 + 当前智能体内“对话 / 配置 / 运行 / 接入”工作区;
费用和平台管理放在树底部的全局区。没有顶层五个任务按钮。
胆量: 先选智能体再操作,让配置/版本/API 示例始终带着同一个对象。
form: 系统中智能体是一等实体,会话与运行都依附于它。
完整版候选。适合创建者,跨智能体排查需要全局运行入口。

## C 聚焦对话 / 轮盘: App 10 原生精修

抽签秒数 S=05;既定暗色工具语境的兼容子集为 App 05/08/10,
5 % 3 = 2,选第3项 App 10;已查看 sheet-app.jpg 和 app/10-native-polish.jpg。
借用: 扁平列表、就地展开、上下文操作,不引入样张的明亮主题。
主角素材: 当前对话和最近会话;管理表格在另一个顶部任务页内。
骨架: 顶部五个任务目的地 + 单一大面板;历史从左抽屉打开,执行详情从右抽屉打开。
胆量: 默认完全撤掉常驻两侧面板,把宽度交还给正文。
form: 对话是长期占用的主任务,辅助信息由当前内容触发。
完整版候选。375px 自然,管理重用户跳转会多一步。

## D 底部运行台 / 现实参照: VS Code

来源: product-facts.md 与 refs/vscode.png,已查看官方截图。
借用: 编辑器下方的运行面板承担输出,文件与对话各有独立空间。
主角素材: 同一轮运行的输入/输出和生成文件。
骨架: 窄导航 + 会话/对话横向分栏 + 底部执行面板。
胆量: 执行详情从右侧改到下面,让长代码输出有完整行宽。
form: 工具输出常是横向代码,底部位置利用其形状。
备选: 小高度屏幕会挤压输入框和对话。

## E 配置与结果并置 / 最佳设计师: Bret Victor 的直接反馈视角

借用: 将正在调整的配置与其结果紧邻,变化有直接反馈。
主角素材: 智能体提示词、契约、试运行对话。
骨架: 顶部对象选择 + 左配置 / 右试运行,全局功能从抽屉进入。
胆量: 把“编辑后再跳去试运行”变成并排工作。
form: 创建者最常做的是调整配置并验证行为。
备选: 不适合作为普通使用者的默认首页。

## F 运行总账 / 轮盘: East 12 日式生活杂志密排

同一秒数 S=05;工具语境兼容子集 East 01/11/12,5 % 3 = 2,
选第3项 East 12;已查看 sheet-east.jpg 与 east/12-japan-magazine-dense.jpg。
借用: 对齐的文字栏、严格分组与高信息密度;不照搬黄底、大字或纸质背景。
主角素材: 运行列表和旁边的结果摘要。
骨架: 全局运行表为首页,侧边上下文详情,顶部任务过滤。
胆量: 从“聊天入口”转到“任务收件箱”。
form: API 密集用户首先关心任务是否完成而不是对话。
备选: 聊天用户第一步会绕路。

## 选择规则

先画六格查看真实骨架,再将 A/B/C 做为三个完整版。
三版差异分别是任务优先、对象优先、对话优先,不只是换颜色和侧栏宽度。
尚无本轮用户选择;正式业务改造要等三版展示后的方向选择。
