# 设计 spec:Open Web Agents 全站重设计

## 项目是什么
企业内部的"智能体平台":用户在工作台和智能体对话(智能体能在会话工作目录里读写文件、跑命令、调用工具),
可以自己设计智能体、发布到市场、签 API Key 让后端调用;管理员维护账号、模型提供者、积分与套餐。

## 受众与场景
- 主要用户:企业内的开发者与业务人员,长时间挂着工作台用,像用 IDE 一样。
- 次要用户:平台管理员,批量处理账号、积分、模型价格,看大量表格。
- 桌面优先(1440),手机能看能发消息即可(375)。

## 核心信息 / 必须呈现的内容(三版同内容)
1. 工作台:智能体选择、会话列表(按时间分组)、对话流(用户消息、工具调用折叠行"Ran 13 tools · EnterPlanMode, Agent ×3 +2 · 1 failed"、Markdown 回复、智能体提问卡片)、输入框(附件、发送)、工作空间文件树。
2. 运行态信息:当前智能体、模型(gpt-6-astra)、计费单价、运行中/空闲、积分余额。
3. 管理页代表:账号管理(311 个账号,每个有邮箱、注册日期、智能体数、本月消耗、月度上限、角色、操作:设为管理员/重置密码/停用)。
4. 导航:工作台 / 智能体市场 / 我的智能体 / AI 编辑 / 账号设置(运行记录、接入中心、审计日志、token 用量、积分账户、积分套餐、平台算力、账号安全)/ 平台管理(账号管理、模型提供者、模型总览、积分管理、套餐与订单、全平台 token 用量)。

## 情感基调
专业、安静、可长时间注视;"这是一件趁手的工具",不是营销页。

## 输出格式与尺寸(三版统一)
- 单文件 HTML,1440×900 首屏;每版内含两屏,用页内切换:①工作台(有对话内容)②平台管理 · 账号管理。
- 截图 1440×900。

## 已知约束
- 风格语境:JetBrains IDE 暗色(参考 `/Users/liuyuhua/github/imux/docs/prototypes/*.html` 与 refs/ 下 JetBrains 官方截图)。
- 已落地的 token(必须沿用):编辑区 #1e1f22、面板 #2b2d30、边框 #393b40、选中 #2e436e、主按钮 #3574f0、链接/运行 #548af7、文字 #dfe1e5、次要 #8c8f96、成功 #5fb865、警告 #e0b153、错误 #db5c5c、IDE 青 #2aacb8、IDE 紫 #c77dbb。
- 字体:Inter Tight(拉丁)+ PingFang SC 回落,等宽 JetBrains Mono;正文 13px(IDE 密度,桌面工具惯例)。
- 实现栈:Next.js + shadcn/ui + Tailwind v4,最终要能落到现有组件上。
