## 1. 路由表

守卫有两种。`requireLogin`：未登录跳 `/login`。`requireAdmin`：未登录跳 `/login`，非管理员跳 `/`。关闭登录（`OWA_AUTH_REQUIRED=0`）时两者都直接放行，后端会发一个匿名 admin。

| 路径 | 页面名 | 谁能看 | 用途 | 重定向 |
|---|---|---|---|---|
| `/` | 智能体工作区（Workbench） | 登录用户 | 和智能体对话，带文件面板、运行树、审批 | 未登录跳 `/login`；`?session=` 是 AI 编辑会话（source=design）时跳 `/agents/design?session=` |
| `/login` | 登录 / 注册 | 未登录 | 登录；首次部署时创建管理员；允许时可注册 | 未开启登录或已登录时跳 `/` |
| `/agents` | 我的智能体 / 智能体配置（Builder） | 登录用户 | 列表；`?new=1` 新建；`?id=` 编辑，分 6 个配置区 | 否 |
| `/agents/design` | AI 编辑 | 登录用户 | 通过对话设计或修改智能体草稿（`?session=`） | 否 |
| `/market` | 发现智能体 | 登录用户 | 浏览已上架的智能体，可使用、克隆、接入 | 否 |
| `/market/[id]` | 智能体详情 | 登录用户 | 说明、示例问题、输入输出契约、操作按钮 | 否 |
| `/settings` | — | — | — | **只是重定向** → `/settings/account` |
| `/settings/account` | 账号安全 | 登录用户 | 修改密码 | 否 |
| `/settings/audit` | 操作日志 | 登录用户 | 本人资源上的操作和本人操作 | 否 |
| `/settings/keys` | API Key 与接入（接入中心） | 登录用户 | Key、调用文档、Webhook；`?agent=` 进入单智能体模式 | 否 |
| `/settings/runs` | 全部运行 / 运行记录 | 登录用户 | 计费在本人名下的运行；可用 `?agent=` 筛选 | 否 |
| `/settings/billing` | 账户与消耗 | 登录用户 | 余额、运行消耗、流水 | 否 |
| `/settings/usage` | 用量分析（token 用量） | 登录用户 | 本人的 token 用量统计 | 否 |
| `/settings/packages` | 充值与订单 | 登录用户 | 选积分包下单、查看我的订单 | 否 |
| `/settings/credentials` | 模型价格 | 登录用户 | 平台算力状态和模型价目表 | 否 |
| `/usage` | — | — | — | **只是重定向** → `/settings/usage` |
| `/admin/accounts` | 账号管理 | 管理员 | 建号、限额、角色、重置密码、停用 | 否 |
| `/admin/providers` | 模型与算力（提供者与路由） | 管理员 | 提供者列表、默认模型别名路由 | 否 |
| `/admin/providers/[id]` | 模型提供者详情 | 管理员 | 凭证、按类型配置的接入地址、模型与价目（`?tab=`） | 否 |
| `/admin/models` | 模型总览 | 管理员 | 所有提供者的模型和售价（只读） | 否 |
| `/admin/capabilities` | — | — | — | **只是重定向** → `/admin/providers` |
| `/admin/billing` | 计费管理 | 管理员 | 概览、账户（发放积分）、对账 | 否 |
| `/admin/packages` | 套餐与订单 | 管理员 | 维护套餐目录、人工确认订单 | 否 |
| `/admin/usage` | 全平台 token 用量 | 管理员 | 全平台用量（scope=all） | 否 |
| `/admin/runs` | 平台运行 | 管理员 | 全平台运行列表 | 否 |
| `/admin/audit` | 平台审计 | 管理员 | 全平台操作记录 | 否 |
| `/admin/market` | 市场管理 | 管理员 | 已发布智能体的上架、下架和分类 | 否 |

## 2. 按区域的功能清单

### 2.0 全局框架与导航（`ide-frame.tsx`、`nav.ts`、`space-shell.tsx`、`user-menu.tsx`、`agent-tree.tsx`、`agent-workspace-header.tsx`）

**顶栏**
- 品牌标识，点击回 `/`。
- 搜索按钮打开跳转面板（NavPalette）。工作台里换成工作台自己的命令面板。
- 移动端有一个“打开智能体树”按钮，以抽屉形式打开。

**左侧栏（264px）**
- 标题默认是“智能体”。右侧的“+”跳 `/agents?new=1`。
- 主体是智能体树（AgentTree）：
  - 智能体超过 5 个或会话超过 10 个时出现搜索框，按智能体名或会话名过滤。
  - 每个智能体可以展开或收起，下面是它的会话（按最近活动排序），最后一行是“+ 新建会话”。
  - 点智能体名跳到哪里，取决于当前所在 tab：配置 → `/agents?id=`，运行 → `/settings/runs?agent=`，接入 → `/settings/keys?agent=`，其他 → `/?agent=`。
  - 同名智能体会显示 ID 前 6 位以示区分。
  - 状态：“正在读取智能体…”；“对象列表加载失败 + 重试”；“还没有智能体”；“没有匹配的智能体或会话”。
  - 有正在进行的运行时，切到其他智能体或新建会话会被禁止。
  - 在工作台里，悬停会话行会出现“会话操作”菜单。
- 全局功能区（固定在侧栏底部）：全部运行（`/settings/runs`）、发现智能体（`/market`）、用量与费用（`/settings/billing`，覆盖 billing、usage、packages、credentials 四个页面的高亮），仅管理员可见的“平台管理”（`/admin/accounts`）。
- 用户菜单：显示邮箱和角色（管理员 / 普通账号 / 本地模式）。菜单项有“账号设置”（`/settings/account`）和“登出”。未登录时显示“去登录”。

**对象页头部（AgentWorkspaceHeader）**
- 进入某个智能体后出现：图标、名称、“智能体工作区”字样。
- 四个 tab：对话（`/?agent=&session=`，会话 ID 存在 sessionStorage 里记住）、配置（`/agents?id=`，没有读配置权限时隐藏）、运行（`/settings/runs?agent=`）、接入（`/settings/keys?agent=`）。

**分区子导航（SpaceShell）**
- 用量与费用：账户与消耗 / 用量分析 / 充值与订单 / 模型价格。
- 账号设置：审计日志 / 账号安全 / API Key 与接入。
- 平台管理：账号管理 / 提供者与路由 / 模型总览 / 计费管理 / 套餐与订单 / 全平台 token 用量 / 平台运行 / 平台审计 / 市场管理。

**跳转面板（⌘K，非工作台页面）**
- 分组：工作区（智能体工作区、智能体配置、新建智能体、发现智能体、全部运行）、用量与费用、账号设置，以及仅管理员可见的平台管理。

**代码中的事实**
- `/settings` 的注释写着“落点须与 PERSONAL_NAV[0] 一致”，但 PERSONAL_NAV[0] 是“审计日志”，实际重定向到的是“账号安全”。
- `status-bar.tsx`（状态栏：在线状态、积分余额、账号）没有任何页面引用，是死组件。

### 2.1 登录（`auth/login-form.tsx`）
- 字段：邮箱、密码（注册时至少 8 位）、注册时还有“再次输入密码”，不一致时报“两次输入的密码不一致”。
- 三种模式：
  - 首次部署：“创建管理员账号”，第一个用户自动成为 admin。
  - 注册：“创建账号”。
  - 登录：“登录以继续”。
- 允许注册（`allowSignup`）或首次部署时，底部显示“还没有账号?去注册 / 已有账号?去登录”切换。
- 按钮状态：“处理中…”。服务端对登录和注册按 IP 和账号限流。

### 2.2 智能体工作区 `/`（`workbench/*`）

**入口与上下文**
- 地址参数：`?agent=` 选智能体；`?session=` 打开历史会话。
- 智能体不存在或无权限时显示“找不到指定的智能体，或你没有访问权限。”；缺少 ID 时显示“链接缺少智能体 ID。”
- 版本规则：
  - 有编辑权限的人跑草稿。
  - 其他人跑已发布版本。
  - 从未发布过的智能体一律跑草稿。
- 头部徽章：运行中 / vN（会话锁定的版本）/ 已发布 vN / 草稿。

**会话标题栏**
- 会话名，新会话显示“新会话”。
- 当前模型和单价（ModelPrice）。
- 两个开关按钮：“查看执行详情”（运行树）、“打开工作空间”（文件面板）。

**右侧工具窗口**
- 可拖动调整宽度（16%–45%），有“工作空间 / 运行”两个 tab 和收起按钮。移动端改为右侧抽屉。

**空状态与错误状态**
- 正在读取会话历史…
- 读取历史失败 + 重试
- 智能体列表没读到 + 重试
- “还没有可用的智能体 / 先创建一个智能体,或请管理员分享给你” + “新建智能体”按钮。注意这个按钮跳的是 `/agents`，不是 `?new=1`。
- “和「X」开始对话” + 智能体描述
- 会话工作目录已被自动清理时的提示条（附清理时间）

**开场建议**
- 新会话、还没有消息时显示智能体配置的 starters（最多 4 条）。内置 default 智能体有 3 条默认建议。

**变量条（VariablePrompt，只在智能体定义了变量时出现）**
- 缺必填变量时：“需要填写 N 个必填变量才能运行此智能体” + “填写变量”。
- 不缺时：“管理变量”链接。
- 弹窗里逐个输入变量，密钥类变量用密码框；有保存和取消。
- 变量值按“用户 + 智能体”保存，可选关联到会话。

**输入框**
- 多行文本，占位文字是“说点什么,或输入 /”；运行中变为“运行中也可以继续补充”。
- 附件：可以在菜单里“添加图片或文件”，也可以全局拖放（会显示“松手添加文件”覆盖层）。单个文件上限 10MB，先上传到会话工作目录，再把附件清单拼进 prompt。
- 斜杠命令：`/new` 新建会话、`/search` 搜索、`/agents` 管理智能体、`/stop` 停止。支持方向键选择、回车执行、Esc 关闭。
- 上下文用量环（ContextWindowMeter）：上限按 200k 计，显示百分比和累计处理量。
- 发送 / 停止按钮。
- 运行中继续发消息时，会先尝试交给正在运行的智能体（steer）。对应提示：“已交给智能体”“已提交,等待智能体接收”“暂时无法确认…”。交不进去时进入排队，排队列表可以逐条取消（显示“排队 N”和附件数）。

**对话流（conversation.tsx）**
- 用户消息；从某轮分叉重跑的会带“⑂ 从上文某轮分叉重跑”标记。
- 思考块：“正在思考...”或“没有可显示的思考内容”。
- 工具调用活动：失败显示红叉，运行中显示转圈；子代理发起的调用会注明。
- 运行中追加的消息（steer 块）；没来得及交给智能体的会标注“已改为本轮结束后发送”。
- 结果卡：只在失败、结局未知、已取消，或有结构化结果时显示；有结构化结果时展示 JSON。
- 每轮底部显示 token ↑输入 ↓输出。
- 每轮的操作：“复制”回答；“重跑”可改写 prompt，优先 rewind 到这一轮之前的状态，定位不到时降级为干净上下文重跑并提示。
- 右侧有轮次导航条（跳到第 N 轮）和“回到最新消息”按钮。

**提问卡片（AskUserQuestion）**
- 支持单选、多选（标“可多选”）和“其他（自己填写）”。
- 剩余时间倒计时，超时后由智能体自行判断。
- 按钮：没答完时显示“请先回答每个问题”（禁用）；答完后是“提交回答”；运行已结束时变成“作为新消息发送”。另有“不回答”。
- 状态：待回答 / 等待中 / 已回答 / 未回答（你选择了不回答）/ 提问无效 / 未回答 / 历史提问。

**审批条（approval-bar.tsx）**
- 待确认卡片显示“agent 在等你确认 —— 原因”、工具和参数，以及“N 后自动拒绝”或“即将超时”。
- 操作：
  - 批准。
  - “批准,本会话内<范围>不再询问”（记住授权）。
  - 拒绝。
  - “拒绝并说明…”，填写的原因会交给智能体。
- “本会话已授权不再询问”列表，每项可单独撤销。
- 读取失败时显示“审批状态读取失败 + 重试”。
- toast 通知：新审批带“批准 / 拒绝”快捷按钮；有提问时提示去对话里回答。

**工作空间（file-panel.tsx）**
- 显示路径 `workspaces/<id8>`，还没有会话时显示“尚未创建”。有刷新按钮，运行中实时刷新。
- 文件树浏览，空目录显示“空目录 / 让 agent 生成点东西”。
- 文件预览：
  - 代码高亮。
  - HTML 和 Markdown 可在“源码 / 预览”之间切换，预览在 sandbox 里渲染（只开 allow-scripts）。
  - 图片、PDF 内嵌显示。
  - 二进制文件提示下载。
  - 过长内容截断。
- 文件操作：复制、下载、关闭。
- 错误：“工作空间不存在”（目录已清理或还没产生文件）、“工作空间读取失败 + 重试”、“预览失败”。

**运行树（run-tree.tsx）**
- 按轮次分组：“第 N 轮 · N 次 · N 失败”。
- 总计“N 次调用 · N 失败”。
- 点开某次调用看详情：输入、输出（运行中… / 没有收到结果 / (空)）、由哪个子代理发起。
- 空状态：“这个会话还没有调用过工具”。

**会话操作（session-actions.tsx）**
- 重命名（弹窗）。
- 归档：从列表消失。**界面里没有查看或恢复归档会话的入口。**
- 删除：确认弹窗说明会停止运行中的任务、删除工作目录，计费记录保留。

**命令面板（⌘K，工作台版）**
- 分组：操作（新会话）、会话（全部会话，显示轮数）、切换智能体（会开一个新会话），再加上全站跳转项。

### 2.3 智能体配置 `/agents`（builder.tsx）

**列表态（没有 `id` 也没有 `new`）**
- 标题“我的智能体”，显示“选择智能体，查看配置或继续编辑”或“正在加载智能体…”。
- 每行显示名称、描述，只读的带“只读”徽章。
- 空状态：“暂无可查看的智能体。”
- 侧栏换成智能体列表：“新建智能体”加“共 N 个”。有输出契约的带“接口”徽章，只读的带“只读”徽章。

**只读态（有读权限、没写权限）**
- 提示“这是只读智能体……请联系所有者”。
- 只有两个 tab：
  - 配置：以 JSON 形式展示脱敏后的配置。
  - 知识：只读，能看资料清单，不能增删。

**编辑 / 新建态的通用元素**
- 标题“智能体配置 / 新建智能体”，面包屑“名称 / 分区名”。
- “AI 编辑”（已有智能体）或“AI 创建”（新建）按钮：
  - 有未保存修改时先弹确认。
  - 然后 POST `/api/agents/design`，跳到 `/agents/design?session=`。
- 6 个 tab，顺序是：配置 → 能力 → 知识 → 安全与契约 → 评测 → 发布与分享。
- 底部固定栏：
  - “保存智能体”，保存中显示“保存中…”。
  - 有改动时显示“有未保存的修改”。
  - Schema 有错时显示“请检查安全与契约中的 Schema”，点击跳到对应 tab。
  - 发布状态徽章：“已发布 vN”“已发布 vN · 草稿有修改”“未发布”。
  - “试运行”：新标签页打开 `/?agent=id`，跑的是草稿。
  - “删除”：仅所有者或 admin 可见，内置的 default 和 agent-architect 不能删。软删除，确认文案说明接口调用、分享、绑定的 Key 都会失效，历史保留，且界面上无法撤销。
- 保存的启用条件：有写权限、有改动、名称和系统提示词都非空、两个 Schema 都合法、当前不在保存中。
- 新建时如果填的 ID 和已有智能体重复，会直接拦截：“ID 已被占用”。
- 未保存保护：关闭标签、站内链接、浏览器前进后退、切换智能体时都会弹 confirm。
- 保存时以已加载的完整配置为底，只覆盖表单里管理的字段，表单不认识的字段原样保留。

#### 2.3.1 「配置」分区
- 名称 *（必填）
- ID：留空自动生成，保存后不能再改。
- 描述
- 开场建议：一行一条，最多取 4 条。
- 系统提示词 *（必填）
- 模型（ModelSelect）：
  - 选项来自 `/api/capabilities`，显示名称和“输入/输出 积分/百万token”。
  - 也可以选“跟随平台默认（别名）”。
  - 当前值已停用时显示“已停用的模型（请重新选择）”。
- 最大轮次：数字，默认 20。

#### 2.3.2 「能力」分区
- **工具白名单**：逗号分隔；留空表示不限制，填了就只允许这些工具。
- **技能（技能包）**：
  - 每个技能可添加或删除，字段有技能名（小写字母、数字、连字符）、描述（何时使用）。
  - `SKILL.md` 正文可折叠展开，显示字符数。
  - 附属文件可添加、编辑、删除。路径校验：不能和已有文件重名，只允许字母数字 `._-` 加 `/`，不能用 `..` 或绝对路径，不能有路径冲突。
  - 空状态：“未配置技能”。
- **MCP 服务**：
  - 每行字段：名称（字母、数字、`_`、`-`）、类型 http / stdio（平台没开 stdio 时该选项禁用，显示“平台未启用”）。
  - http 类型填 URL。
  - stdio 类型填 command、args（每行一个）、env（字符串键值 JSON，格式错误时保存报错）。
  - 每行有“测试连接”：会带上本人保存过的变量值。结果显示“连接成功：服务名、协议、N 个工具（未调用）”或错误信息。
  - 有删除按钮；空状态“未配置 MCP 服务”。
- **子代理**：
  - 字段：名称、何时使用（description）、模型（默认“同主 agent”，限同一模型组；不兼容时提示）、提示词。
  - 只有名称和提示词都填了才会保存。`background` 固定为 false。
  - 可删除；空状态“未配置子代理”。

#### 2.3.3 「知识」分区（knowledge-panel、knowledge-upload、knowledge-search）
- 必须先保存智能体，否则提示“保存智能体后添加知识文档”。
- 说明文字：知识按智能体保存，跨会话有效；运行时按问题检索片段注入提示词。
- 用量：已用 N/上限篇、字数/上限字、单篇上限。
- 超出篇数上限的旧文档标“不参与检索”，并附说明。
- 上传文件：可多选，可拖放。支持 PDF、docx、pptx、xlsx、文本，单个 20MB 以内，只保存提取出的文字。长文档会自动切成多篇。结果显示页数和字数。
- 手动添加：标题和正文，“添加文档”。
- 文档列表：标题、字数、删除（确认后不可恢复）。点开可看正文，有编辑（标题和正文）、保存、取消。
- 检索测试（有文档时出现）：
  - 输入问题后显示命中片段、得分和顺序。
  - 可展开“查看实际注入给模型的文本”。
  - 没命中时提示“这个问题运行时不会带入任何资料”。
- 只读者（被分享的人）：提示“可以看资料清单，但不能增删”。

#### 2.3.4 「安全与契约」分区
- **变量与密钥**：
  - 每个变量：变量名（自动转大写，只保留 `A-Z0-9_`）、说明、必填、密钥（加密存储，不进提示词）。
  - 在配置里用 `{{变量名}}` 引用。
  - 空状态：“未定义变量…”。
- **权限模式**（6 选 1，带提示文字）：询问权限（default）、自动接受编辑、规划模式、自动判定、跳过权限检查（选它时追加提示“子代理会一并继承”）、从不询问。
- **无人值守审批**：按入口默认（接口调用放行）/ 一律拒绝 / 一律放行。说明文字：网页里始终等人审批。
- **需审批的工具**：逗号分隔。
- **需审批的命令模式**：逗号分隔。
- **Webhook 回调 URL**：仅所有者和 admin 可填，其他人看到“（已隐藏）”且输入框禁用。运行终态时推送，用“接入”页设置的密钥签名。
- **inputSchema**：JSON Schema，可选。实时校验，顶层必须是对象。填了以后 invoke 的入参不符合会返回 400。
- **outputSchema**：JSON Schema，可选。实时校验，可点“填入示例 schema”，合法时显示“schema 合法”徽章。
- 底部链接（已保存的智能体才有）：“前往接入，管理 API Key 与调用示例”，跳 `/settings/keys?agent=`。

#### 2.3.5 「评测」分区（eval-panel、eval-form）
- 必须先保存，否则提示“保存智能体后添加评测用例”。只有有写权限的人能看到这个面板。
- 说明：每个用例会真实调用一次模型，费用记在你名下。发布要求：对当前草稿的评测全部通过，且之后没改过配置或用例。
- 用例列表：用例名、断言摘要、编辑、删除（历史评测记录保留）。
- 用例表单：
  - 用例名 *、输入 *。
  - 输入是否按 JSON 对象解析：智能体有 inputSchema 时默认勾选，此时必须是 JSON 对象。
  - 期望运行成功：取消勾选表示期望失败。
  - 正文须包含（每行一个）、正文不得包含（每行一个）。
  - 结构化字段等于：每行写“路径 = 值”，值按 JSON 解析，解析不了就当文本。
  - 花费上限（美元，正数）、耗时上限（秒，正数）。
  - 保存用例 / 取消。
- 运行评测：
  - 先选目标：草稿（已保存的）或 v1…vN（当前发布版有标记）。
  - 确认框里显示用例数和花费提示。没有用例时按钮禁用。
  - 表单有未保存修改时提示“评测跑的是已保存的草稿”。
- 历史评测列表：版本或草稿、配置哈希、“= 当前草稿”“= vN”“配置已变化”“用例已改动”等标记、通过数/总数（百分比）、时间。
- 评测详情：运行中每 2 秒自动刷新。每个用例显示通过 / 未通过 / 未能运行 / 运行中、花费、耗时、运行 ID、失败原因，以及判分时的输出快照（文本或结构化结果；未通过的默认展开）。

#### 2.3.6 「发布与分享」分区（release-panel、share-panel）
- 必须先保存，否则提示“保存智能体后管理发布与分享”。版本面板只对有写权限的人显示。

**版本与发布**
- 徽章：未发布 / 已发布 vN / 草稿有未发布的修改。
- 说明文字：
  - 未发布时：接口调用和其他用户都直接用草稿。
  - 已发布后：他们用发布版；调用方可以用 `version` 锁定某一版。
- 版本说明输入框（可选，最多 512 字）+ “发布为 vN”。
- **发布的约束**（前后端都校验，后端返回 409 `eval_required` 或 `nothing_to_publish`）：
  - 表单没有未保存修改。
  - 草稿和当前发布版有差异。
  - 草稿评测状态为 passed：至少 1 个用例、对当前草稿内容全部通过、之后用例没改过。
- 评测状态文案：no_cases / none / running（每 3 秒刷新）/ cases_changed / failed / passed。
- 草稿和发布版相同时提示“没有可发布的修改”。

**版本列表（每一版）**
- 显示 vN、当前发布标记、该版评测标记、时间。
- 操作：
  - “回滚到此版”（比当前发布版旧时）或“设为发布版”：只需确认，**不受评测限制**，秒级生效，进行中的会话不受影响。
  - “对比草稿”。
  - “对比上一版”。
  - “载入草稿”：用这一版覆盖草稿，已发布版本不受影响。表单有未保存修改时禁用。
- 对比结果：每处改动标“新增 / 删除 / 修改”，长文本给出行级差异。

**分享**
- 只有所有者可操作，否则提示“这个智能体不归你管”。
- 只有两个动作：“公开给所有账号”（固定为只读的 `public` 授权）/“取消公开”。
- “遗留的定向授权”列表（用户或组），可逐条撤销。
- 公开不等于上架市场，上架要管理员在 `/admin/market` 操作。

**配置项中 builder 没有暴露的字段**（保存时原样保留）：`effort`、`escapeHatch`、`approvalRules.all`、`icon`、子代理的 `background`、旧字段 `skills`（保存时清除）。这些在 AI 编辑的“模型、工具与契约” JSON 里可以改，但 `escapeHatch` 和资源类字段是被禁止的。

### 2.4 AI 编辑 `/agents/design`（design-workspace.tsx）
- 面包屑：我的智能体 › AI 编辑 › 目标名（或“新智能体”）。右上角有“平台算力”字样，有目标智能体时有“配置与发布”链接跳 `/agents?id=`。
- 顶部工具条：
  - “设计记录”下拉，可切换历史设计会话；有未保存修改或忙碌时禁用。
  - “新建设计”。
  - 移动端在“设计对话 / 设计草稿”之间切换。
- 空状态：“用对话设计一个智能体” + “开始新设计”。载入中显示 spinner。
- **左栏：设计对话**
  - 对话流，和工作台共用 ChatThread，支持提问卡片作答。
  - 审批条。
  - “从试运行结果反馈”：列出目标智能体的试运行记录（成功 / 失败 / 取消、输入、时间），点“反馈给 AI”会把输入、输出和错误拼成一段提示词填进输入框。
  - 输入框（例：把输出改成 JSON），发送或停止。有未保存修改时提示“发送前会保存当前设计草稿”。
- **右栏：设计草稿**

  - 特殊状态：

    - conflict：“目标智能体已被修改，当前设计不能直接覆盖”。

  - AI 出错时显示 aiIssue。
  - 字段：
    - 名称、说明、系统提示词。

  - Skills / MCP 来源：
    - 从已有智能体里选一个作为资源来源，可添加、移除。

    - 被勾选的 MCP 可以测试连接，但必须先保存草稿。
  - 技能包（inline）只读预览：文件数，可展开查看。
  - MCP（inline）列表：名称、类型、URL、env 键名，可测连接（须先保存）。
  - 校验问题列表（field: message）。
  - “保存设计草稿”。
- **差异与保存弹窗**
  - 显示配置变更 diff 和冲突、校验问题。有冲突、有问题或没有 previewToken 时“确认保存”禁用。
  - 文案：“保存不会创建或切换发布版本”。
  - 保存调用 `/api/agents/design/apply`，toast“已保存「X」草稿”。保存之后**还要回到 builder 去评测和发布**。

### 2.6 接入中心 `/settings/keys`（`integration/*`）
- **模式**
  - 全局模式：标题“API Key 与接入”，有“选择智能体”下拉。
  - 单智能体模式（`?agent=`）：标题“API 接入”，显示对象页头部和“全部 API Key”链接。
  - 错误：“找不到指定的智能体…”；智能体列表加载失败 + 重试。
- 三个 tab：API Key / 调用文档 / Webhook。
- **API Key tab**
  - 说明：Key 只在后端用，明文只显示一次。显示平台默认的每 Key 每分钟限额和每智能体合计限额，超出返回 429。
  - 签发表单：
    - 用途备注。
    - 每分钟上限。
    - 有效期：不过期 / 30 天 / 90 天 / 1 年。
    - 限定智能体：不限，或“仅 X”。
  - 签发后显示一次性明文，有“复制”和“我已保存”。
  - 列表每行：
    - 名称、限定的智能体、过期状态（已过期 / N 小时后过期 / 日期）、最近使用或“从未使用”。
    - 每分钟限额：行内编辑，可保存、恢复默认、取消。
    - 月度积分上限：行内编辑，显示本月已用/上限，可设为不限额。
    - 轮换：立即签发新 Key，旧 Key 24 小时后失效。
    - 吊销：确认后立即生效。
  - 状态：载入中、暂无 key、加载失败 + 重试。
- **调用文档 tab**
  - 先选智能体。
  - 徽章：已发布 vN / 未发布 · 调用使用草稿；结构化入参或文本入参；结构化结果或文本结果。
  - “OpenAPI 文档”链接（`/api/agents/:id/openapi.json`）。
  - 版本说明：可用 `version` 锁定某一版；草稿里有未发布修改时说明不影响调用方。
  - 调用代码 tab：curl / Python / Node。示例入参按 inputSchema 生成并做校验，说明是否通过；可复制。代码里覆盖 invoke、轮询 result、事件流、文件列表和下载。
  - “运行记录”链接跳 `/settings/runs?agent=`。
  - 空状态：还没有可调用的智能体（附去创建的链接）、请选择智能体。
- **Webhook tab**
  - 回调地址展示，没有时显示“尚未配置回调地址”。
  - “配置回调地址”跳 `/agents?id=`，落在“配置”tab，而回调地址字段实际在“安全与契约”tab。
  - 投递记录（只有所有者能看）：成功或失败、触发方式（测试 / 运行 xxx · 第 N 次）、未签名警告、单条“重发”、“刷新”、“发送测试”、“加载更多”。
  - 非所有者看到：“回调地址与投递记录由智能体所有者管理”。
  - 签名密钥卡（账号级，所有智能体共用）：
    - 签名算法说明（X-OWA-Signature、X-OWA-Timestamp）。
    - 当前掩码或“未配置”。
    - 可自定义密钥（至少 24 字符）、生成、重新生成（旧密钥在一段时间内会继续用 Previous 头额外签名），可清除。
    - 新密钥只在当时显示一次。

### 2.7 运行记录（`runs/runs-view.tsx`）

### 2.9 计费（`billing/*`）
- **个人 `/settings/billing`**：三个 tab。

  - 运行消耗：
    - 消耗汇总可按来源、智能体、API Key 分维度看；时间范围有本月 / 上月 / 近 30 天 / 近 90 天。列有次数、实际扣除、欠额、冻结中、合计。

- **管理员 `/admin/billing`**：三个视图。
  - 概览：全平台消耗汇总，多一个“按账号”维度；点账号跳到“账户”视图并带上时间段。
  - 账户：
    - 选择账号（标注已停用）、刷新。
    - “批量发放积分”：每行或逗号分隔一个邮箱，上限见常量；填每人积分和说明；先预览（可发放 / 跳过原因），再确认发放；失败的可“用原批次重试”。
    - 单账号人工发放：积分数量和说明，确认弹窗说明“不代表支付渠道已收款”。
    - 下面是和个人页一样的三个 tab。
  - 对账：
    - 选起止日期，有刷新和“导出 CSV”。
    - 按日期和提供者统计：运行数、各类 token、成本估算（元）、应扣、实际扣除、不完整数据。超过 5 万次运行会提示截断。
    - 待核对（所有账号）：按原因筛选（欠款 / 用量未知 / 无法完整计价），**只列出，没有处理操作**。
- **充值与订单 `/settings/packages`（用户）**
  - 说明：固定积分包，长期有效；管理员人工处理；在线支付和自动扣费都没启用。另有“查看积分账户”链接。

  - 我的订单：状态有待人工处理 / 积分已发放 / 已取消；未发放的可“取消订单”；可加载更早的。
- **套餐与订单 `/admin/packages`（管理员）**

  - 订单管理：多一列账号；“人工确认”时填确认说明，发放积分。
- **文案不一致（事实）**：`price-list` 写着“积分扣款尚未启用”，而 billing 页描述了冻结、结算、扣除的流程。

### 2.10 模型与提供者（管理员，`models/*`）
- **`/admin/providers`**
  - tab“提供者”：
    - 表格列：名称、API Key（已配置或未配置）、文本接入、模型数、启用或停用。
    - “添加提供者”弹窗：名称、文本接入地址（Anthropic 协议，可稍后填）、API Key（可稍后填）。
    - 有刷新；空状态和错误重试。
  - tab“默认模型路由”：先选所属提供者，再给 fable / opus / sonnet / haiku 四个别名各选一个模型（必须同一提供者），然后“保存别名映射”。
- **`/admin/providers/[id]`**
  - 有“返回列表”。
  - 基本信息：名称、启用。停用时弹确认，显示影响 N 个智能体和哪些别名。
  - API Key：加密保存，只能替换不能查看，按钮是“替换 / 保存”。
  - 按类型（文本 / 生图 / 生视频 / 语音合成 / 语音转写）配置接入地址：
    - 协议：Anthropic / OpenAI 兼容 / 自定义；地址；保存。
    - 测试：填测试用模型标识，“测试连接”，结果为成功或 HTTP 错误。
    - 非文本类型提示“暂未接入运行时，不提供测试”。
  - 每种类型的模型表：名称 / 标识、成本单价（元）、加价、售价（积分）、状态、版本、编辑；还有“添加模型”。
- **模型弹窗**
  - 字段：显示名称、模型标识、加价比例（%，不超过 1000%）、单次运行冻结积分（留空用平台默认，用到八成会自动追加）、启用、支持图片输入、各计量项的成本单价（元，最多 8 位小数）。
  - 自动换算：1 元 = 100 积分，乘以加价得到售价。
  - 警告：加价低于充值赠送比例；旧价目单位非标准。
  - 停用时显示影响的智能体和别名。每次保存生成新版本。
- **`/admin/models`**：按类型列出模型、提供者、售价、加价、状态，点名称跳到对应提供者页。
- **`/settings/credentials`（用户，标题“模型价格”）**：算力来源固定为“平台统一提供”；平台配置状态为“已配置”或“待配置，请联系管理员”；有“用量分析”和“账户与消耗”链接；下面是按类型的价目表（积分/单位，不可用的标注出来）。

### 2.11 账号管理 `/admin/accounts`（admin/accounts-view.tsx）
- 副标题：N 个账号 · N 个启用中 · 本月消耗。
- 筛选：按邮箱、按角色（全部 / 管理员 / 普通账号）。
- 创建账号：邮箱和角色，创建后弹窗显示一次性初始密码。
- 表格列：邮箱（标注“你自己”“已停用”、旧上限警告）、角色、注册日期、智能体数、本月消耗、月度上限。
- 右侧详情：
  - 月度上限：留空表示不限，0 表示禁止消费，超过后新运行被拒。
  - 设为或取消管理员。
  - 重置密码：生成新的一次性密码。
  - 停用或恢复：停用会立即登出并停用该账号的 Key；恢复后 Key 需要重新签发。
  - 不能对自己改角色或停用。

### 2.12 审计（`audit/*`）
- 个人版“操作日志”和平台版“平台审计”。
- 按操作类型筛选，约 50 种：智能体、知识、Key、审批、账号、登录、Webhook、评测、提供者、模型、计费、套餐、订单、用户组、克隆等。
- 列：时间、操作者、操作、内容、来源地址。有刷新和加载更多。

### 2.13 账号安全 `/settings/account`
- 修改密码：当前密码、新密码（至少 8 位）、再次输入，有不一致提示，按钮“修改密码”。

## 3. 角色矩阵

只有两个平台角色：`admin` 和 `user`（`users.role`）。“构建者”和普通用户是同一个角色，任何登录用户都能创建、配置、发布智能体，也能签发 Key。第一个注册的用户自动成为 admin。关闭登录的本地模式下，所有人都被当作 admin。

另外，每个智能体还有自己的资源权限，规则是：所有者有全部权限，admin 对所有智能体也有全部权限，其他人看授权记录（read 或 write，write 包含 read）。

| 能力 | 普通用户（作为所有者） | 被授 write 的协作者 | 只读 / 公开 / 市场使用者 | 管理员 |
|---|---|---|---|---|
| 新建智能体、AI 创建 | ✓ | ✓ | ✓ | ✓ |
| 编辑配置、知识、评测、发布、回滚 | ✓ | ✓ | ✗（只读 JSON 和知识清单） | ✓（所有智能体） |
| 查看或修改 Webhook URL、投递记录 | ✓ | ✗ | ✗ | ✓ |
| 公开、取消公开 | ✓ | ✗ | ✗ | ✓ |
| 删除智能体 | ✓（内置的除外） | ✗ | ✗ | ✓ |
| 跑草稿 / 试运行 | ✓ | ✓ | ✗（只能跑已发布版） | ✓ |
| 立即使用、克隆、API 接入（市场） | ✓ | ✓ | ✓ | ✓ |
| 签发 Key、Webhook 签名密钥 | ✓（本人） | — | — | ✓ |
| 看自己的运行、用量、计费、订单、审计 | ✓ | ✓ | ✓ | ✓ |
| 看别人的会话 | ✗ | ✗ | ✗ | ✗（会话是私有的，admin 也不越权） |
| 上架市场 | ✗ | ✗ | ✗ | ✓ |
| `/admin/*` 全部页面 | ✗ | ✗ | ✗ | ✓ |

前端判断：`isAdminView(me)` 决定“平台管理”入口和跳转面板分组是否显示，`requireAdmin` 负责页面守卫。

## 4. 主流程现状：新建 → 配置 → 评测 → 发布 → 接入

| 步骤 | 所在页面 / 组件 | 操作路径（最少点击） | 断点（代码中的事实） |
|---|---|---|---|
| **新建** | `/agents?new=1`（Builder 的“配置”tab） | 入口有 5 个：侧栏“+”、⌘K“新建智能体”、Builder 列表里的“新建智能体”、工作台空状态按钮、市场“克隆”。然后填名称和系统提示词，点底部“保存智能体”。最少 1 次点击 + 2 个字段 + 1 次保存。 | ① 工作台空状态的“新建智能体”跳的是 `/agents` 列表，还要再点一次“新建”。② 知识、评测、发布三个 tab 在保存前都只显示“保存智能体后…”。③ 新建页没有对象头部（对话 / 运行 / 接入 tab），保存后 URL 变成 `?id=`，侧栏从“智能体列表”换成“智能体树”，布局会跳变。 |
| （可选）AI 创建 | `/agents/design` | Builder 点“AI 创建”→ 跳转 → 对话 → “差异与保存”→“确认保存” | 保存只写入草稿，不评测也不发布。要回 Builder 得点头部的“配置与发布”链接（新设计保存后才有 targetId）。跳转前如有未保存修改，要连续确认两次。 |
| **配置** | Builder 的 6 个 tab | 配置、能力、知识、安全与契约，每个 tab 都要切过去 | 和发布相关的 Webhook URL、input/outputSchema、变量、权限都在“安全与契约”里。Schema 出错时底部有跳转链接。试运行是在新浏览器标签打开 `/?agent=`。试运行结果只有在 AI 编辑里能通过“从试运行结果反馈”拿来用，Builder 里看不到。 |
| **评测** | Builder 的“评测”tab（EvalPanel） | 切 tab → 添加用例 → 填写 → 保存用例 → 选目标 → 运行评测 → 确认。最少约 6 次点击。 | 必须先保存，评测跑的是已保存的草稿。每次运行都真实计费。改了配置或用例后，之前的评测结论作废。 |
| **发布** | Builder 的“发布与分享”tab（ReleasePanel） | 切 tab →（可选填版本说明）→“发布为 vN” | 发布有硬性门槛：至少 1 个用例且对当前草稿全部通过，没有跳过的办法。发布区文案写“在下方「评测」里添加用例”，但评测是排在发布**前面**的另一个 tab。回滚和设为发布版不受评测限制。公开和上架是两回事：所有者只能“公开”，上架市场必须由 admin 在 `/admin/market` 操作，界面里没有申请流程。 |
| **接入** | `/settings/keys?agent=`（AccessCenterView） | 入口：“安全与契约”底部链接、对象头部“接入”tab、市场“API 接入”。然后签发 Key（填表 → 签发 → 复制 → 我已保存）→ 调用文档 tab 复制代码 → Webhook tab 配签名和测试。 | 接入中心在“设置 / 账号设置”分组下（PERSONAL_NAV），而不在智能体对象里。Webhook URL 在 Builder 里配，投递记录和签名密钥在接入中心，签名密钥是账号级的。“配置回调地址”跳 `/agents?id=`，默认落在“配置”tab，而不是“安全与契约”。Key 的限额只能在列表里逐行编辑。 |

**整体**：一条完整链路至少要经过 2 个页面（`/agents` 和 `/settings/keys`）和 Builder 内 4 到 5 个 tab，保存要发生 2 次以上（新建、改完配置后再存一次才能评测）；走 AI 编辑还要多一个页面。

## 5. API 中有、UI 里没有入口的能力

| API | 能力 | UI 现状 |
|---|---|---|
| `GET/POST /api/groups`、`GET/POST/DELETE /api/groups/[id]/members` | 用户组的创建和成员管理 | 完全没有界面。nav 注释说明组在“一个账号即一家企业”的模型下被有意去掉 |
| `POST /api/agents/[id]/share`，target 为用户邮箱或组，permission 为 write 或 read | 把智能体定向分享给某个人或组，可给写权限 | SharePanel 只能公开（只读），遗留的授权只能撤销 |
| `POST /api/runs/[id]/cancel` | 按运行 ID 取消 | 运行列表和详情里没有取消按钮；工作台用的是 sessions/cancel |
| `GET /api/sessions/[id]/branch` | 会话内的运行分支树 | 没有展示（只有“重跑”时用 POST） |
| `POST /api/sessions/[id]/branch`，mode=continue | 从某次运行之后继续分支 | UI 只用了 rewind 和 fresh |
| `PATCH /api/sessions/[id]`，archived=false；sessions 列表默认过滤掉归档 | 查看或恢复归档会话 | 只有“归档”，没有归档列表，也没法恢复 |
| `GET /api/agents/[id]/versions/[version]` | 查看某个版本的完整快照 | 只能通过 diff 间接看 |
| `POST /api/agents/[id]/invoke`、`GET /api/agents/[id]/result`、`GET /api/sessions/[id]/events` | 对外异步调用、结果轮询、事件流 | 只出现在调用代码示例里，没有在线调试或“试一次 invoke”的界面 |
| `GET /api/agents/[id]/openapi.json` | OpenAPI 文档 | 只有一个链接，没有渲染 |
| 配置字段 `effort`、`escapeHatch`、`approvalRules.all`、`icon`、`subagents[].background` | 推理强度、逃生舱、全量审批、图标、后台子代理 | Builder 表单没有。effort 等只能在 AI 编辑的 parameters JSON 里改，escapeHatch 被禁止 |
| `PUT /api/me/credentials` | 旧的自带模型 Key（BYOK） | 已废弃，返回 410，审计里还保留 `me.credentials_update` 标签 |
| `GET /api/health` | 健康检查 | 运维用，无 UI |
| 审计标签 `billing.mode_update`（切换计费模式） | — | 没有对应的界面或 API 入口（只剩标签） |
| `GET /api/admin/billing-pending` | 待核对记录 | 只能查看，界面明确写着“不提供核销、退还或确认结清等处理操作” |
| `status-bar.tsx`（积分余额、在线状态） | 组件已实现 | 没有页面引用 |
