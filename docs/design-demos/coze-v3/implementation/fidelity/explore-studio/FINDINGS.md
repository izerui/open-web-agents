# 还原度排查 · explore-studio（探索 / 智能体详情 / 登录 / 工作室 / 新建弹层 / 顶栏外壳）

排查方式：原型用 `file://` 打开，产品看 5678（普通账号 design-review）和 5679（本地模式）。两边都在 1440×900 下截图，拼成左右对照图（左原型、右产品），原始截图在 `raw/`。市场列表、最近会话、推荐、详情这几处的接口用 playwright `page.route` 塞了模拟数据。

## 发现

**F1 推荐区里点「立即使用」，不会把刚说的那件事带进对话**
- 页面：`/` 说一件事 → 推荐 → 交给某个智能体「立即使用」
- 原型：链接是 `chat.html?agent=…&q=<输入的那句话>`，进了对话，输入框里已经是刚才那句话。
- 产品：`start(a.id,{mode})` 没带 `question`。实测跳到 `/chat?session=sess-x`，地址里没有 `q`，用户进对话还得再打一遍。
- 对照图：`explore-suggest.png`
- 类别：交互不同。严重度：**高**（首页主流程在最后一步断了）
- 代码：`src/features/explore/ask-panel.tsx:219`
- 建议：改成 `start(a.id, { mode, question: result.text })`，`chatHref` 已经支持 `q`。

**F2 市场卡片和详情页的「API 接入」，进去是只读的「编排」页，看不到接入信息**
- 页面：`/` 市场卡片、`/market/<id>` → API 接入
- 原型：去 `build.html?agent=…#acc`，也就是接入阶段（调用地址、签 Key）。
- 产品：链接是 `/agents/<id>?stage=access`。但对不是自己的智能体（`canWrite=false`），构建页只渲染第一个阶段，`stage=access` 被忽略。实测落在「编排 · 只读」，没有调用地址、契约和签 Key 入口。
- 对照图：`raw/explore-api-prod.png`
- 类别：交互不同 / 可能的缺陷。严重度：**高**
- 代码：`src/features/market/market-actions.tsx:179`；`src/features/build/build-page.tsx:457`（`readOnly ? STAGES.slice(0, 1)`）和 `:857`
- 建议：给只读者和市场使用者一个精简的接入视图（调用地址、契约、去 API Key 页签 Key），或者把按钮指到市场版的接入说明。

**F3 普通注册没有「再次输入密码」，前端也不做逐项校验**
- 页面：`/login`
- 原型：注册和首次部署都有「再次输入密码」。按钮一直可点，点了以后在字段下面逐项给红字：请输入邮箱 / 邮箱格式不对 / 请输入密码 / 密码至少 8 位 / 两次输入的密码不一致。
- 产品：只有首次部署才有确认密码。没填完时按钮置灰。邮箱格式靠浏览器原生气泡。密码少于 8 位要等服务端返回，错误显示在表单上方的红条里，不在字段下面。
- 对照图：`login-signup.png`、`login-shortpw.png`
- 类别：交互缺失 / 效果不同。严重度：中
- 代码：`src/features/auth/login-form.tsx:44`（`needConfirm` 只在首次部署成立）、`:48-52`、`:130`（form 没加 `noValidate`）、`:186`
- 建议：注册一律要求确认密码；加 `noValidate`，做前端逐字段校验（含 8 位下限），错误写在各字段下面，按钮不再预先置灰。

**F4 登录失败后密码框不清空、焦点不回去；成功也没有提示**
- 原型：密码错误时清空密码框并聚焦；成功时提示「登录成功 / 账号已创建」。
- 产品：密码错误后密码还在，焦点也不在密码框（实测）；成功后直接跳转，没有提示。
- 对照图：`raw/login-wrongpw-prod.png`
- 类别：效果缺失。严重度：低
- 代码：`src/features/auth/login-form.tsx:63-70`
- 建议：出错时清空密码并聚焦；成功后弹 `toast.success`。

**F5 首页和登录页那排头像，中间本该是智能体设计器（黑底白眼），现在成了米色**
- 原型：7 个头像中间那个是黑底白眼的智能体设计器。
- 产品：第 5 个写的是 `avatar:#1F1E1C:white`，但白眼只许设计器用，这个 icon 被丢掉，退回按 id 算出来的米色。
- 对照图：`explore-default.png`、`login-default.png`
- 类别：视觉偏差。严重度：低
- 代码：`src/features/explore/avatar-row.tsx:5-13, 30-41`；`src/lib/agent-avatar.ts:28, 43`
- 建议：第 5 个直接用 `id="agent-architect"`，不传 icon。

**F6 「正在工作」的会话卡片没有步骤进度**
- 原型：回复下面有步骤清单，已完成的打勾，当前步骤转圈，然后才是「看执行过程」。
- 产品：只有最近一段回复文字（或「正在处理这件事…」）和「看执行过程」按钮。
- 对照图：`explore-work.png`
- 类别：效果缺失。严重度：中
- 代码：`src/features/explore/recent-work.tsx:264-277`；接口 `/api/sessions/recent` 目前没返回步骤
- 建议：`lastRun` 里带上最近 3 条工具调用或计划步骤，按原型样式渲染。

**F7 首页选的附件只提示一下，不会跟着进对话或设计器**
- 原型：附件变成一个胶囊，旁边「添加文件」还在，附件随这件事一起走。
- 产品：选完显示胶囊，同时提示「附件会在对话里上传：选好智能体、进入对话后再把文件拖进去」。之后不管点「立即使用」还是「用设计器创建」，文件都不会带过去；选了一个以后「添加文件」按钮就消失了。
- 对照图：`explore-attach.png`
- 类别：交互不同。严重度：中
- 代码：`src/features/explore/ask-panel.tsx:88-127`
- 建议：建完会话就把文件上传进去；做不到的话，至少在推荐区写明「附件要进对话后再传」。

**F8 「立即使用」成功没有提示（卡片、详情页、推荐区都一样）**
- 原型：先提示「已用「X」vN 新建会话」再跳转。产品：直接跳转。
- 类别：效果缺失。严重度：低
- 代码：`src/features/market/market-actions.tsx:60-68`

**F9 断网时的错误文案是英文「Failed to fetch」**
- 页面：市场区加载失败、详情页加载失败（凡是走 `errorText` 的地方都一样）
- 原型：「网络异常或服务暂时不可用（请求超时）」。
- 产品：服务端出错时文案正常（「服务暂时不可用」）；但网络中断时显示「Failed to fetch。你的会话和智能体不受影响。」
- 对照图：`explore-market-error.png`；断网那次只有脚本输出的文字记录
- 类别：文案。严重度：中（全站问题）
- 代码：`src/lib/fetch-json.ts:53-55`
- 建议：`errorText` 认出网络错误（`TypeError` / `Failed to fetch`），统一翻成「网络异常，连不上服务」。

**F10 详情页的「版本说明」只有当前版本**
- 原型：列出最近 3 个版本，各带日期和改动要点。产品：只有当前一条。
- 对照图：`detail-full.png`
- 类别：效果缺失。严重度：低

**F11 详情页加载骨架只有头部**
- 原型：骨架有头部、左栏几行说明、示例问题卡和右栏价格卡。产品：只有头部骨架和「正在加载…」，下面是空白。
- 对照图：`detail-loading.png`

**F12 只读抽屉的「克隆一份来改」只对已上架的智能体能用，点了也不先确认**
- 原型：任何只读智能体都能克隆；先弹确认框（新 ID 为 `xxx-copy`，配置和知识一并复制，密钥变量要重填），确认后进构建页。
- 产品：没上架的直接置灰，说明「只有已上架市场的智能体可以克隆」；已上架的一点就克隆，不弹确认。
- 对照图：`studio-readonly.png`
- 类别：交互不同。严重度：中（如果「只能克隆已上架」是刻意的规则，就只差确认框，降为低）
- 代码：`src/features/studio/readonly-drawer.tsx:44, 117-129`
- 建议：先确认规则；保留限制的话，补一个和市场一样的确认框。

**F13 本地模式（5679）下工作室分组不对：所有智能体都算成「分享给我的」**
- 原型：没有本地模式这个状态。按信息架构，本地模式的匿名管理员应当被当成所有者。
- 产品：页签是「我建的 0 / 分享给我的 130 / 全部 131」，每张卡都带「可编辑」徽标，「我建的」永远是空的。
- 对照图：`shell-cmdk-local.png`、`shell-me-local.png`（右边背景就是这一页）
- 类别：可能的缺陷。严重度：中
- 代码：`src/features/studio/studio-model.ts:34-37`（只看 `isOwner`）；`/api/agents` 在本地模式下 `isOwner` 为 false
- 建议：本地模式下接口把 `isOwner` 判为 true，或者前端按 `authRequired === false` 处理。

**F14 本地模式下积分胶囊不见了，头像菜单是三行「本地模式」**
- 原型：顶栏一直有积分胶囊；头像菜单依次是姓名、邮箱、角色，「积分与套餐」右边显示余额。
- 产品（5679）：`/api/billing` 返回「账号不存在」，积分胶囊被隐藏，但菜单里还留着「积分与套餐」入口（大概率点进去也报错）。头像菜单的姓名、邮箱、角色三行都是「本地模式」。普通账号（5678）下菜单里的「积分与套餐」也没有余额数字。
- 对照图：`shell-me-local.png`、`shell-me-user.png`
- 类别：视觉偏差 / 可能的缺陷。严重度：低
- 代码：`src/components/shell/top-nav.tsx:20-33, 95-101`；`src/components/shell/me-menu.tsx:70-73, 107-115`
- 建议：本地模式下菜单只显示一行「本地模式（匿名管理员）」并隐藏积分入口，或者让 billing 接口返回 0；菜单里的「积分与套餐」带上余额。

**F15 ⌘K：没有「新会话」，没标题的会话显示成一串 ID，智能体没有状态**

- 对照图：`shell-cmdk-user.png`、`shell-cmdk-local.png`

## 核对过、和原型一致（或产品更好）的部分
- **探索**：
  - 输入框：回车发送、Shift＋回车换行；空发送提示「先写下想交给它的事」并聚焦；示例胶囊填入后直接发送。
  - 推荐区：设计器卡、现成智能体、「市场里暂时没有直接对应的智能体」三种内容都对。
  - 「用设计器创建」把描述带到 `/agents/new`。
- **最近会话**：列表切换正常；正在工作、成果已交付、已回复、失败四种状态都对；没有会话时有空态。
- **市场**：
  - 分类、计数、搜索、最常用/最新排序都对；选「最新」时徽标换成「MM-DD 发布」。
  - 无结果空态：清除筛选，或让设计器做一个（带上「做一个X助手」）。
  - 加载骨架、失败 + 重试、暂无上架三种状态都对。
  - 卡片悬停上浮、整卡点进详情、克隆确认后进构建页都正常。
- **详情**：
  - 示例问题点了会带着 `q` 进对话；复制契约有提示。
  - 价格卡和基本信息都对；加载、失败、不存在（404）三种状态都有。
- **登录**：登录/注册切换、首次部署的管理员提示、处理中状态（按代码核对）都对。
- **工作室**：
  - 列表：页签带计数；搜索和无结果态（清除搜索）；卡片/列表切换会记住选择；各种徽标。
  - 更多菜单：复制 ID、新建会话、运行记录、接入、删除；内置的和别人分享的会写明不能删的原因。
  - 删除：确认框列出三条后果，删完有提示并从列表移除。
  - 只读抽屉的配置/知识两个页签都对。
- **新建弹层**：
  - 设计器方式：默认选中；从探索带来的描述会预填并聚焦；示例能填入；空描述报错。
  - 空白创建：名称必填、ID 格式、ID 被占用都有提示；选的头像会生效。
  - 克隆：列表、搜索、无匹配都对。
  - 模板：选中后名称跟着变，有提示词开头预览，建好进构建页。
  - Esc 关闭后地址回到 `/agents`。
- **375 宽**：首页、工作室、新建弹层、详情、登录都没有横向溢出（市场分类页签是故意做成横向滚动的），手机上的按钮都是 44px。对照图 `mobile-375-prod.png`。

## 总结
整体还原度约 **85%**。最该先修的 5 条：
1. **F1** 推荐区「立即使用」不带用户说的那句话
2. **F2** 市场「API 接入」落到只读编排页，看不到接入信息
3. **F3** 普通注册没有确认密码，也没有逐项校验
4. **F13** 本地模式下工作室所有智能体都算成「分享给我的」
5. **F6** 「正在工作」卡片没有步骤进度（另有 F9 网络错误显示英文，全站问题，改一处即可）
