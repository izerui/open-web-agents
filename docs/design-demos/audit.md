# 全量体检:页面与交互问题清单(2026-10-27)

截图:`/tmp/owa-audit/*.png`(1440×900 与 375×812)。覆盖 25 条路由 + 命令面板、智能体选择、头像菜单、对话页。

## 结构性问题(换皮解决不了,需要重新设计)

1. **三个"空间"各自一套外壳,没有统一的应用框架**。工作台、账号设置、平台管理都是"左侧栏 + 顶栏 + 主区",但侧栏内容、顶栏结构各不相同;从工作台进设置靠头像菜单,回去靠"返回工作台"。IDE 里这是一个窗口:主工具栏 + 工具窗口条 + 编辑区 + 状态栏。
2. **设置/管理页是"居中窄栏 + 浮卡片"的网页表单**,左右各留 400px 空白,和 IDE 的"设置树 + 右侧表单"完全不是一个物种。
3. **信息密度过低**。账号管理 311 个账号,每个账号一张 170px 高的卡片,一屏只看到 4 个;应是表格(一行 32px,一屏 25 行)。套餐页、模型价格同样问题。
4. **页面骨架不统一**:有的页面标题带副标题、有的没有;刷新按钮有时在顶栏、有时在每个区块右侧(积分管理一页 5 个刷新按钮);主操作有时在顶栏右上("添加提供者"),有时在区块里("添加模型")。
5. **错误态是裸文本**:"HTTP 404" 红字直接出现,且和"载入中…"同时显示(积分账户、套餐页)。没有错误原因、没有重试入口的统一样式。
6. **空状态敷衍**:AI 编辑页是一整屏黑底中间一个按钮;工作台右侧工作空间在没有会话时占 260px 只放一行灰字。
7. **工作台缺少运行态的"仪表"**:积分余额、当前模型、运行状态、连接状态散落各处或没有;IDE 用底部状态栏承载这些。
8. **对话区**:工具调用折叠行、Markdown 正文、提问卡片三种东西视觉层级接近,长对话里很难扫读;提问卡片的"请先回答每个问题"是禁用态主按钮,读起来像可点。

## 交互与响应式缺陷

9. **375 宽下工作台主区只有 292px,右侧留一条 83px 空白**(工作空间面板隐藏后空间没让出来)。
10. **375 宽下接入中心横向溢出**:签发 Key 那一行输入框被截断,出现横向滚动条。
11. 命令面板里同名智能体出现两次("Existing agent" ×2),无法区分(数据如此,但界面应附 id 或归属)。
12. 账号管理的"停用"是红字链接样式,和"重置密码"并排、距离很近,危险操作没有隔离。
13. 原生 `<select>`(账号角色)与自绘 Select 混用,同一行高度、箭头样式不同。

## 已在上一轮修掉的

色板、字号、圆角、焦点环、选中态、写死颜色、半透明输入框、标题栏高度不齐。
