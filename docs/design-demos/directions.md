# 六张方向卡(语境:JetBrains IDE 暗色)

## 候选 1 · 最佳设计师 · JetBrains New UI 团队 → 「IDE 外壳」(选为 dir-1)
- **逻辑与来源**:IntelliJ 2022 起的 New UI 设计团队的思路(refs/newui.png、imux 原型)。不是模仿某个截图,而是用他们的规则从头组织这个产品。
- **借的是什么**:主工具栏 40px(左:项目组件=智能体选择器,中:运行组件=运行状态/停止,右:搜索/通知/头像);左侧 40px 工具窗口条(图标:会话、智能体、市场、运行记录、设置);工具窗口 + 编辑区 + 右侧工具窗口三栏;编辑区顶部 tab(每个打开的会话是一个 tab);底部 24px 状态栏(积分余额、模型、连接、运行状态)。
- **主角素材**:界面本身的结构 —— 工具窗口条与状态栏。
- **骨架**:窗口式四边框(工具栏/工具条/状态栏)包住三栏。
- **胆量花在哪**:会话变成编辑区 tab,可以同时开几个会话并排切换;设置/管理变成"设置窗口"(左树右表单,顶部面包屑)。
- **form 来自内容的哪里**:用户"长时间挂着工作台像用 IDE 一样",会话就是文件。

## 候选 2 · 最佳设计师 · JetBrains Fleet 团队 → 「Fleet 静谧」(选为 dir-3)
- **逻辑与来源**:Fleet 的克制派做法(refs/fleet.png):浮起的圆角面板悬在更暗的底上,面板之间 6px 缝。
- **借的是什么**:#141518 底 + 圆角 10px 面板;每个面板自带 tab 行;顶部只有一行极简标题栏(居中:智能体 · 会话名);命令面板(⌘K)是主导航,侧边不放导航条;对话是居中单栏,最大 760px。
- **主角素材**:留白与面板之间的缝。
- **骨架**:三块独立浮面板(会话 / 对话 / 工作空间),无外框。
- **胆量花在哪**:去掉一切常驻导航,所有跳转走 ⌘K;管理页同样是浮面板里的表格。
- **form 来自内容的哪里**:对话是核心,其余都应该退后。

## 候选 3 · 现实参照 · DataGrip / IntelliJ Services 工具窗口 → 「控制台 · 主从」(选为 dir-2)
- **逻辑与来源**:DataGrip 首页截图(refs/datagrip.png)里 agent 会话就在编辑区 tab 中,数据库浏览器是树,数据是网格;IntelliJ 的 Services 工具窗口是"左树 + 右详情"。
- **借的是什么**:主从分栏(左列表 32px 行、右详情);数据网格(表头 28px、斑马纹关闭、行 hover #393b40、选中 #2e436e、列可排序);工具调用以"运行树"呈现(像调试器的帧/Run 窗口的测试树,带状态图标和耗时);顶部是窄工具栏行(图标按钮 + 过滤输入)。
- **主角素材**:数据网格与运行树。
- **骨架**:每个页面都是"左树/列表 | 右详情"的主从结构。
- **胆量花在哪**:对话右侧常驻"运行树"面板,把每一轮的工具调用、耗时、token 以树展示;账号管理是 311 行的真表格 + 右侧详情抽屉。
- **form 来自内容的哪里**:智能体运行本质是一棵调用树;管理员面对的是成百上千行数据。

## 候选 4 · 现实参照 · JetBrains AI Assistant 工具窗口(备选)
- **借的是什么**:对话放在右侧工具窗口,主区留给工作空间文件编辑器;消息流紧凑,代码块带"插入/复制"操作。
- **骨架**:主区是文件编辑器,对话在右侧 400px。
- **为何备选**:和候选 1 外壳相同,差异只在对话与文件的主次;对"主要是对话"的产品,把对话塞到侧窗是倒置。

## 候选 5 · 秒数轮盘 · 网页 #10 包豪斯(语境不兼容)→ 顺延 #11「暗色双色侧栏开发者」(备选)
- **借的是什么**:左固定侧栏锚点导航 + 右侧长文档滚动,等宽小标签,单 accent。
- **用在哪**:设置与管理页做成一份长文档,左侧锚点高亮当前段落。
- **为何备选**:适合设置页,但撑不起工作台;且"等宽编号小标签"是模板装饰的高发区。

## 候选 6 · 秒数轮盘 · 东亚 #6 香港招牌(语境不兼容)→ 顺延 #7「中国传统色·节气色谱」(备选)
- **借的是什么**:用低饱和传统色给每个智能体一个身份色(竹青、天水碧、缃色、苍筤……),出现在 tab 图标、会话行小色点、运行树。
- **为何备选**:是一个可以叠加到任何方向上的"细节系统",单独撑不起骨架。可在选定方向后作为增强项。
