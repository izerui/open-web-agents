# coze-v3 阶段 2：探索与市场 Implementation Plan

> 依据：总计划 `2026-11-12-coze-v3-redesign.md`「阶段 2 探索与市场」、`docs/design-demos/coze-v3/features.md` §2.1 / §2.5、`gaps.md` A1 / A2 / A10 / A11，原型 `prototype/explore.html`、`market-detail.html`、`login.html`。

**Goal:** `/` 换成探索首页（说一件事 → 推荐；你的 AI 同事正在工作；市场），`/market/[id]` 重做为整页详情，`/login` 改成左右两栏卡片；后端补 A1 意图推荐、A2 最近会话、A10 作者与使用次数、A11 每次约花费。

**Architecture:** 纯打分 / 状态判断 / 数字格式化放在 `src/lib/modules/*/domain`，先测后写；MySQL 读模型各加一个批量查询（不按卡片逐个查）；前端新组件放 `src/features/explore/`，市场详情与登录在原文件里重排，业务逻辑（建会话、克隆、登录提交）沿用原实现。`MarketView` 继续给 `/admin/market` 用，不删。

## Task 1：A1 意图推荐打分（纯函数）

- 用例：
  - 空串 / 只有停用词（「帮我做一个助手」）→ 空数组
  - 「整理今天的会议纪要」→ 名称含「会议纪要」的排第一，说明里有「纪要」的排后
  - 英文不区分大小写：「sql 查询」命中名称「SQL 助手」
  - 示例问题（starters）与类别名也参与打分；名称权重 > 示例问题 > 说明 / 类别
  - 只命中单个汉字不算命中（「的」「我」不推荐任何东西）
  - 同分时 `mine` 优先、再按使用次数、再按名称；最多返回 limit 个
- 验收：`pnpm vitest run src/lib/modules/market/__tests__/suggest.test.ts` 绿

## Task 2：A10 / A11 显示格式与作者（纯函数）

- `authorOf("lin.zhou@x.com")` → `lin.zhou`；空 / 非法 → null
- `formatUseCount`：0 → 「暂无使用」；1234 → 「1,234 次使用」；18000 → 「1.8 万次使用」；10000 → 「1 万次使用」
- `formatPerRun`：null → null；0.004 → 「不到 0.01 积分/次」；0.5 → 「约 0.5 积分/次」；2.34 → 「约 2.3 积分/次」；12.6 → 「约 13 积分/次」
- 验收：`stats-display.test.ts` 绿

## Task 3：市场列表带统计（application + 适配器）

- `catalog-stats.test.ts`（内存仓储 + 假 stats）：
  - list 结果每项带 `author / useCount / avgCredits`，stats 只被调用一次、入参是全部可见智能体（批量）
  - stats 抛错时列表照常返回，字段为 null / 0
  - detail 同样带字段
  - 没有注入 stats（旧调用方）时字段为 null / 0
- `mysql-market-stats.mysql.test.ts`（需 `OWA_TEST_DATABASE_URL`，否则跳过）：近 90 天以外的运行不计数；eval / design 来源不计；平均只取最近 50 次成功且已结算的运行；作者取邮箱前缀
- 验收：两份测试绿（mysql 测试在测试库上跑一次并记录）

## Task 4：`GET /api/market/suggest`

- `suggest-route.test.ts`（照 `routes.test.ts` 的 fixture）：未登录 401；q 超长 400；q 为空返回 `{items:[]}`；命中上架智能体返回 `mine:false`；所有者自己的未上架智能体命中时返回 `mine:true`；未上架且不是自己的不出现；最多 3 条；不泄露提示词等私有字段
- 验收：测试绿

## Task 5：A2 `GET /api/sessions/recent`

- `recent-work.test.ts`：`workStatus` —— pending/running → running；success 且有文件 → delivered；success 无文件 → replied；failed → failed；cancelled → cancelled；没跑过 → idle。`latestFile` —— 只取文件、跳过隐藏文件与目录、取 mtime 最大，空 → null
- `route.test.ts`（假 container）：未登录 401；只查本人 web 会话（断言传给 `sessions.list` 的过滤条件）；按最近运行时间倒序取 5 个；附带 `agent.name`、`lastRun.status/prompt/reply`、`file`；读文件失败时该会话不带文件卡但不报错
- 验收：测试绿
