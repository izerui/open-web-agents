# coze-v3 阶段 4：工作室 Implementation Plan

> 依据：总计划 `2026-11-12-coze-v3-redesign.md`（阶段 4 段落）、原型 `docs/design-demos/coze-v3/prototype/studio.html`（`shots/studio*.png`）、`features.md` 2.3 列表态 / 只读态 / 删除、`gaps.md` A12、A14。

**Goal:** `/agents` 换成原型的「我的智能体」（卡片 / 列表、页签、搜索、状态徽标、更多菜单、只读抽屉、各种状态），新建统一成一个弹层（智能体设计器 / 空白 / 从市场克隆 / 模板库），补上模板库后端（A14）。

**Architecture:** 新组件放 `src/features/studio/`，只用阶段 1 的 `AppShell`、`AgentAvatar` 与 `ui/*`。可测的判断（分组、徽标、筛选、计数、ID 校验、删除资格、时间文案、空白创建的请求体）抽到 `studio-model.ts` 纯函数。后端：`GET /api/agents` 加 `isOwner / updatedAt / runs7d`（一条聚合 SQL）；`POST /api/agents` 加 `createOnly`（新建时 ID 被占用一律 409，不会误改已有智能体）；模板库是代码内静态目录，`GET /api/agents/templates` 列出、`POST /api/agents/from-template` 建草稿（内部交给 `POST /api/agents`，鉴权、校验、审计同一份）。Builder 的编辑态不动，继续服务 `/agents/[id]`。

## Task 1: 模板库（A14 后端）

- 测试：恰好 6 个，id 唯一，名称为 报销初审 / 客服问答 / 周报生成 / 会议纪要 / 合同比对 / SQL 助手；每个有说明、非空系统提示词、模型别名属于 `MODEL_ALIASES`、1–4 条开场建议、头像 icon 能被 `avatarStyle` 解析；`templateCreateBody("sql")` 产出 name / description / icon / config(systemPrompt、model、starters)；自定义名称覆盖；未知 id 返回 null；返回的配置不与目录共享引用
- `GET /api/agents/templates`：未登录 401；登录返回 6 个
- `POST /api/agents/from-template`：未知模板 400；缺 templateId 400；正常时以模板内容（+ 自定义名称 / ID）交给 `POST /api/agents`，带 `createOnly`，返回 201 与智能体

## Task 2: `/api/agents` 扩展

- GET 测试（mock container）：自己的智能体 `isOwner:true`、分享来的 `false`；`runs7d` / `updatedAt` 来自 `agentActivity.of`，且只调用一次、传入的是可见的非市场条目 id、窗口起点是 7 天前；市场条目（只用权）不带这些字段
- POST 测试：`createOnly` + 已占用 ID（含已删除）→ 409 `id_taken`；不带 `createOnly` 时原行为不变
- 实现：`MysqlAgentActivity.of(ids, sinceMs)`：`agents LEFT JOIN sessions LEFT JOIN runs(created_at >= since) WHERE agents.id IN (...) GROUP BY agents.id, agents.updated_at`

## Task 3: 工作室纯逻辑

- `studioKind`：default / agent-architect → builtin；`isOwner` → mine；否则 shared
- `studioBadges`：已发布 vN（success）、草稿有修改（warning，仅可写且有未发布修改）、未发布、内置（dark）、只读 / 可编辑（outline，分享来的）、已上架、接口（有输出契约）
- `filterStudio(list, tab, q)`：页签 + 名称 / ID / 描述不区分大小写；`studioCounts`：我建的 / 分享给我的 / 全部
- `validateNewAgentId(id, taken)`：留空合法；`^[a-z0-9][a-z0-9-]{1,35}$`；占用 → 「ID 已被占用」
- `deleteBlock(agent)`：内置 → 「内置智能体不能删除」；非所有者且非管理员（`canManageWebhook` 为假，与 Builder 一致）→ 「只有所有者或管理员可以删除」；否则 null
- `formatUpdated(ts, now)`：今天 HH:mm / 昨天 / MM-DD / YYYY-MM-DD
- `blankCreateBody({name, id, description, icon})`：名称去空格；ID 留空不传；系统提示词给占位默认值；`createOnly:true`
- `studioAgents(list)`：去掉只有市场使用权的条目（`canRead === false`）

## Task 4: 页面与弹层

- StudioView：衬线标题、副标题（加载后「共 N 个……」）、右上「新建智能体」；页签（数量）、搜索、卡片 / 列表切换；卡片照原型；加载骨架、失败重试、空状态、搜索无结果（清除搜索）、页签为空
- 卡片点击：可写 → `agentHref({id})`；只读 → 抽屉（只读说明、脱敏配置 JSON、知识清单（`KnowledgePanel canWrite={false}`）、对话、克隆一份来改：仅已上架且已发布的才能克隆（克隆接口的既有规则），否则按钮禁用并说明）
- 更多菜单：复制 ID、新建会话、运行记录、接入（只读不显示）、删除（禁用时显示原因）；删除确认弹窗沿用 Builder 文案（接口调用、分享立即失效，绑定的 Key 调不通；历史保留；界面上不能撤销；已上架的会下架）
- 新建弹层：四种方式，设计器默认；设计器 → `POST /api/agents/design` → `/agents/new?designer=<id>&desc=<描述>`；空白 → 校验 → `POST /api/agents`（createOnly）→ `agentHref`；克隆 → `/api/market` 列表可搜索 → 克隆接口；模板 → 模板列表 + 可改名称 + 提示词预览 → from-template
- `/agents/new`：渲染 StudioView 并打开弹层（`?desc=` 预填，`?mode=` 选方式）；关闭弹层回到 `/agents`
