# coze-v3 阶段 3：对话 Implementation Plan

> 依据：总计划 `2026-11-12-coze-v3-redesign.md`（阶段 3 范围）、`docs/design-demos/coze-v3/features.md` 2.2 节、原型 `prototype/chat.html` 与 `shots/chat*.png`。

**Goal:** 把 `/chat` 按 chat 原型重排：AppShell 全幅外壳 + 左栏会话列表（按天分组、搜索、新会话弹层、行菜单、已归档视图可恢复、设计器会话标记）+ 主区对话卡片（对话头、变量条、对话流、提问卡片、审批条、输入框）+ 右侧可拖宽面板（工作区文件 / 执行详情）。features.md 2.2 节每一条保留。

**Architecture:** 页面状态仍集中在 `workbench.tsx`（运行、排队、steer、重跑、历史还原的逻辑原样保留），布局拆成 `session-list.tsx`（左栏）、`chat-header.tsx`（对话头）、`new-session-dialog.tsx`（选智能体弹层）、`composer.tsx`（输入框）。`conversation.tsx` / `approval-bar.tsx` / `file-panel.tsx` / `run-tree.tsx` 保持 props 驱动（阶段 5 的「试聊」和现在的智能体设计器都复用），只换样式并新增可选 props（定位工具调用、只读、文件面板的「让智能体生成点东西」回调）。可测的判断全部放进纯函数（`chat-view.logic.ts`、`conversation.logic.ts`、`workbench.logic.ts`）。

**Tech Stack:** Next.js 16 App Router、React、Tailwind v4、shadcn new-york、vitest、playwright。

## 文件结构

- Create `src/features/workbench/chat-view.logic.ts` —— 列表分组（今天/昨天/更早）、搜索、版本徽标、新会话弹层的智能体分组与「跑草稿还是已发布 vN」说明、设计器会话跳转地址、智能体链接（自己的→构建页、其他→市场）、附件清单拆分
- Create `src/features/workbench/__tests__/chat-view-logic.test.ts`
- Modify `src/features/workbench/conversation.logic.ts` —— `ToolCall.key`（toolUseId 或序号），供对话流与执行详情互相定位；`toolCallLocator`
- Modify `src/features/workbench/workbench.logic.ts` —— `promptFromSearch`（`?q=` 预填）
- Create `src/features/workbench/{session-list,chat-header,new-session-dialog,composer}.tsx`
- Modify `src/features/workbench/{workbench,conversation,approval-bar,file-panel,run-tree,session-actions,variable-prompt,context-window-meter}.tsx` —— 原型样式
- Modify `src/app/chat/page.tsx` —— 设计器会话改为直接跳 `/agents/<目标>?designer=`（经 `/agents/design?session=` 解析，不变）
- Modify `src/lib/modules/session/{ports.ts,ports.contract.ts,adapters/*}` —— `SessionListFilter.archivedOnly`
- Modify `src/lib/modules/run/{ports.ts,ports.contract.ts,adapters/*}` —— `RunStats.active`（未结束的运行数，列表里画运行中转圈）
- Modify `src/app/api/sessions/route.ts` —— `?archived=1` 只列归档、`?include=design` 带上设计器会话、列表不回 `designState`、带 `activeRuns`
- Create `src/app/api/sessions/__tests__/list-route.test.ts`
- Modify `src/app/globals.css` —— 删除 `.object-frame`、`.ide-layout`、`.workbench-*` 规则（确认无引用）
- Modify `playwright/{object-workspace,object-state-regressions,ask-user,workbench-agent-param,media-preview}.spec.ts` —— 按新结构改可访问名称与选择器
