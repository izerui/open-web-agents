# coze-v3 阶段 6：开发者与账户 Implementation Plan

> **For agentic workers:** 按任务顺序执行；纯逻辑先写失败的 vitest 测试再实现；界面用浏览器对照原型验证。

**Goal:** 把 `/developer/keys`、`/developer/runs`、`/account/{billing,usage,prices,security,audit}` 按原型 `prototype/dev-*.html`、`account-*.html` 重做，直接用 `AppShell side="developer" | "account"`，不再经 SpaceShell；`/account/packages` 并入 `/account/billing?tab=packages`；现有能力一项不丢，并补上「取消运行」（API 已有、UI 没有）。

**Architecture:** 页面框架（衬线大标题、说明、右侧操作、内容宽度）抽成 `SpacePage`；共享视图（RunsView、BillingView、UsageView、AuditView、PackageView、AccessCenterView）里的「内容」与「外壳」分开 —— 个人页走 `SpacePage`，`/admin/*` 与 `/agents/[id]?stage=*` 仍走原来的 SpaceShell（阶段 5、7 再换）。纯判断（Key 到期、限额校验、运行可否取消、账单页签、流水类型、审计分组、用量条形）抽成纯函数并测试。

**Tech Stack:** Next.js 16 App Router、React、Tailwind v4、shadcn new-york、vitest、biome。

**原型：** `docs/design-demos/coze-v3/prototype/{dev-keys,dev-runs,account-billing,account-usage,account-prices,account-security,account-audit}.html` 与 `shots/`。
