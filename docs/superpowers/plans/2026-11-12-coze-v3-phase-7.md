# coze-v3 阶段 7「平台管理」Implementation Plan

> 总计划：`2026-11-12-coze-v3-redesign.md`。共同简报：`.superpowers/sdd/2026-11-12-coze-v3-redesign/phase-common.md`。

**Goal:** 平台管理六页（账号、模型与提供者、市场上架、套餐与订单、计费、平台运行与用量）按 `prototype/admin-*.html` 重排，直接用 `AppShell side="admin"`；补 A15 用户组管理与 A13 上架申请审核端（含所有者端接口，供阶段 5 调用）。

**Architecture:** 管理页统一用新的 `AdminPage`（AppShell + 衬线标题 + 说明 + 操作 + 地址同步的页签 `?tab=`）。只给管理员用的视图（账号、模型、市场管理、套餐管理）在 `src/features/admin/` 下重写或搬移；与个人页共用的视图（RunsView、UsageView、AuditView、BillingView）尽量在外层组合：`SpaceShell` 新增「嵌入」上下文，嵌在 `/admin/ops` 页签里时只渲染说明与操作条、不再套外壳，三个共享视图本身不改；BillingView 只改 admin 分支的标题与页签样式。A13 新增 `market_listing_requests` 表与 `ListingRequests` 应用服务，批准时复用 `AgentMarket.setListing`。

**Tech Stack:** Next.js 16 App Router、React、Tailwind v4、shadcn、drizzle/mysql2、vitest。

## 组的归属规则（读 `/api/groups` 后的结论）

- 组按「创建者」归属（`groups.owner_id`）；`GET /api/groups` 默认只列自己建的，`?scope=all` 仅对 admin 生效（非 admin 静默降级为 self）。
- 成员管理（`/api/groups/[id]/members`）只允许组的创建者或 admin；其他人一律 404。
- 管理页按管理员语义：列表用 `scope=all`，看全平台的组，可管理任意组成员；新建的组归当前管理员。
- 缺口：没有删除组的接口 → 新增 `DELETE /api/groups/[id]`（创建者或 admin；同时收回所有 `principalType=group` 指向它的智能体授权，记审计 `group.delete`）；列表缺「创建者邮箱」「用在几个智能体的授权上」→ `GET /api/groups` 追加 `ownerEmail`、`grantCount`（只加字段）。
